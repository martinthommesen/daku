# daku v1 specification

Hand-off-ready product and architecture spec for **daku**: a ServiceNow-first infrastructure monitoring app for the platform owner. Decisions were made via the [wayfinder map](https://github.com/martinthommesen/daku/issues/1); this document narrates them. Detail lives in ADRs, `CONTEXT.md`, closed tickets, and research notes — this file does not re-argue them.

**Status:** accepted ([#16](https://github.com/martinthommesen/daku/issues/16)) — hand-off-ready for build.

---

## 1. Purpose and audience

daku gives the **Operator** (platform owner) a local macOS glance view of ServiceNow **Environments** (default: prod / test / dev): are they up, are jobs stuck, are MIDs healthy, is there drift after a clone, are integrations failing silently?

It is **not** an on-call pager, a multi-user portal, or a multi-platform observability suite in v1.

## 2. Glossary

Canonical terms: root [`CONTEXT.md`](../../CONTEXT.md).

| Term | Meaning |
|------|---------|
| **Platform** | Product family daku monitors — v1 is ServiceNow only |
| **Environment** | One instance of a Platform (config-driven list) |
| **Signal** | Named observation collected from an Environment |
| **Credential** | Secrets to read an Environment (keychain; never git) |
| **Operator** | Person running daku — v1 = platform owner alone |
| **Environment health** | Rollup: healthy / degraded / down |

## 3. Product shape

| Decision | Choice |
|----------|--------|
| Who | Operator only (no daku login) — [#6](https://github.com/martinthommesen/daku/issues/6) |
| Where | Local machine; reaches Environments over VPN |
| Mode | **Dashboard only** — open and look; no alerts in v1 — [#12](https://github.com/martinthommesen/daku/issues/12) |
| Scope | ServiceNow-concrete; nav model is Platforms → Environments — [#7](https://github.com/martinthommesen/daku/issues/7) |
| Data | Sensitive by default; no cloud sync |
| Licence | **GPL-3.0-only**, public repo — [ADR-0002](../adr/0002-gpl-3.0.md) |

## 4. Architecture

- **UI:** GPUI native desktop (macOS-only); shell components and theme tokens from gpui-component, system light/dark — [ADR-0001](../adr/0001-native-gpui-rust-daemon.md), [ADR-0008](../adr/0008-gpui-component-shell.md)
- **Collector:** Rust daemon + versioned protocol + native client (local in v1; hostable later)
- **Bootstrap:** Partial one-time fork of [egoist/waku](https://github.com/egoist/waku) — GPUI `src/`, daemon, protocol, `waku-core`, SQLite migration pipeline; strip agent domain; do not track upstream — [ADR-0003](../adr/0003-partial-fork-one-time.md)
- **Not inherited:** waku web client as v1 UI; agent features (composer, terminal, browser, …)

Research: [`docs/research/waku-reuse.md`](../research/waku-reuse.md) (note: early research leaned web; **overridden** by ADR-0001).

## 5. Environments and Signals

### Environments

- Default template: **prod / test / dev**; test and dev treated as **clones of prod** (drift and last-clone first-class).
- List is **config-driven** — Operator can add/remove without a code change.
- A PDI may stand in while building; it is not a monitored Environment the team relies on. Hostnames stay local (never in the public tracker).

### v1 Signal set (7)

Driven by pains: stuck jobs, dead MID, post-clone drift, silent integration failure, unnoticed upgrade — [#9](https://github.com/martinthommesen/daku/issues/9).

1. Availability — up/latency + build probe  
2. Scheduled jobs — overdue / error  
3. MID / ECC — health + queue backlog  
4. Syslog error rate  
5. Version + plugin/app drift across Environments  
6. Last-clone date (from prod / clone source)  
7. Outbound / integration failures  

Surfaces and roles: [`docs/research/servicenow-signals.md`](../research/servicenow-signals.md).

### Freshness and health

- Poll cadence ~**2 minutes**, one cadence for all Environments in v1.
- **Environment health** rollup: healthy / degraded / down from Signals; hard-coded defaults (e.g. overdue job → degraded; unreachable → down).
- Trends: **~24h** for syslog error rate and job backlog; other Signals point-in-time.

## 6. Auth, credentials, collector semantics

[ADR-0004](../adr/0004-servicenow-auth-and-credentials.md) · research [`docs/research/servicenow-api-access.md`](../research/servicenow-api-access.md)

| Topic | v1 rule |
|-------|---------|
| Real Environments | OAuth 2.0 **client credentials**; Machine/WSAO user; `snc_read_only` + custom read role on polled tables |
| PDI / stand-in | Basic auth allowed |
| Secrets | macOS Keychain (daku-owned service) |
| Non-secrets | `~/.daku/` (e.g. `environments.json`), dir `0700`; daemon-written files `0600`; `https://` URLs only |
| Rate limits | Polite Table/Aggregate queries; honour 429 / `Retry-After` |
| Outcomes | **reachable** · **unreachable** · **asleep** (PDI hibernate) — distinct from “up but unhealthy” |

## 7. Storage

[ADR-0007](../adr/0007-local-sqlite-storage.md)

- **SQLite** (waku drizzle → SQL → rusqlite/WAL pipeline; schema replaced).
- Path: under **`~/.daku/`** (e.g. `app.db`), dir `0700`, db `0600`.
- Persist latest snapshot per Signal × Environment; ~24h ring for syslog + jobs; prune aggressively.
- No alert-history store.

## 8. UI

[ADR-0005](../adr/0005-environments-overview-layout.md) · [ADR-0008](../adr/0008-gpui-component-shell.md) · prototype [`prototypes/environments-overview/`](../../prototypes/environments-overview/)

**Home screen = sidebar + Environment detail** (prototype variant C):

- Sidebar: Environments (health dots) — the Platforms group returns when a second Platform exists (ADR-0005 amendment).
- Main: selected Environment header + Signal cards + “vs other Environments” compare strip + a Drill-in region under the cards when a card is selected.
- Matrix layout deferred as a possible secondary drift view, not the home screen.

(Prototype is HTML with waku colour tokens; implementation target is GPUI.)

## 9. Packaging and distribution

[ADR-0006](../adr/0006-macos-packaging.md)

- Primary: notarised **`.app` / DMG** + **Sparkle** (Apple Developer ID required).
- Alternate: **Homebrew cask** — upgrades via `brew`; Sparkle off/no-op in cask builds.
- Public GPL-3.0-only; handing a colleague a build is intentional distribution with source on GitHub.

## 10. Out of scope (v1)

From the [map](https://github.com/martinthommesen/daku/issues/1):

- Alerting / notifications (rules, channels, quiet hours, ack)
- Connector / plugin seam for a second Platform
- Access control to daku itself (login, roles)
- waku’s coding-agent domain
- Any monitored Platform other than ServiceNow
- Building the app (this document is the build input, not the build)

## 11. Ready for build / still local

|-------------------|-------------------------------------------|
